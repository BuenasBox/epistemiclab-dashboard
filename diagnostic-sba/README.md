# Diagnostic SBA

Práctica diagnóstica formativa: organiza presentación, estilos y comportamiento sin modificar scoring ni contratos de evaluación.

## Archivos

- `index.html` — marcado y orden de carga de dependencias.
- `diagnostic-sba.css` — estilos propios de la experiencia, incluida su paleta original.
- `diagnostic-sba.js` — interacción, sesión y presentación diagnóstica.
- `preguntas.json` — metadatos públicos de la experiencia.

Este refactor no modifica la lógica de scoring, Supabase Edge Functions, `admin/` ni simulaciones legadas.
