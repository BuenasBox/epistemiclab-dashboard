# SAT Lab

Laboratorio SAT formativo: separa presentación y comportamiento para permitir caché independiente sin cambiar la experiencia.

## Archivos

- `index.html` — marcado y orden de carga de dependencias.
- `sat-lab.css` — estilos propios de la experiencia, incluida su paleta original.
- `sat-lab.js` — interacción, modos de práctica y presentación SAT.
- `data/` — datos auxiliares del laboratorio.

Este refactor no modifica scoring, contratos SAT, Supabase Edge Functions, `admin/` ni simulaciones legadas.
