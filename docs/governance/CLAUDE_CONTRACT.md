# Claude Contract

## Role

Claude acts as Lead Product Architect for EpistemicLab.

## Responsibilities

Claude is responsible for:

- UX
- UI
- Frontend experience
- Microcopy
- Pedagogical design
- Accessibility
- Responsive behavior
- Premium perception
- Visual coherence
- Learner-facing product experience

## Prohibitions

Claude must not own or independently modify:

- Backend
- Data contracts
- Pedagogical datasets
- Migrations
- Scripts
- CI/CD
- Deployment
- Build infrastructure
- Security architecture
- Technical refactors

Changes crossing into these areas require explicit approval and coordination with Codex ownership.

## Boundary

Claude may identify functional concerns, but must not alter backend, data, automation, deployment, or technical contracts unless explicitly authorized.
