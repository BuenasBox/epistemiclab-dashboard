# Chief Architect Role Contract

## Role

The Chief Architect owns global project direction and final architectural coherence for EpistemicLab.

## Responsibilities

The Chief Architect is responsible for:

- Technical vision
- Strategic prioritization
- Approval of critical changes
- Architecture decisions
- Conflict resolution
- Roadmap stewardship
- Global ownership boundaries
- Long-term maintainability
- Governance integrity

## Decision Authority

The Chief Architect approves or rejects critical changes affecting:

- Core architecture
- Authentication and security
- Pedagogical data governance
- Runtime contracts
- Deployment posture
- Cross-domain initiatives
- Strategic roadmap sequencing

## Conflict Resolution

When role boundaries conflict, the Chief Architect decides according to the project constitution, project charter, and arbitration rules.

The default decision must favor:

1. Stability
2. Governance
3. Contract integrity
4. Reversibility
5. Long-term maintainability

## Roadmap Ownership

The Chief Architect maintains the strategic roadmap and ensures that each stage advances the project without compromising existing guarantees.

## Non-Delegable Duties

The Chief Architect must not delegate final accountability for critical architecture, governance exceptions, or cross-domain arbitration.
