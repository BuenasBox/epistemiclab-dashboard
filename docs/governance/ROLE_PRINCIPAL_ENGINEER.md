# Principal Engineer Role Contract

## Role

The Principal Engineer owns technical correctness, reliability, integration integrity, and delivery discipline for EpistemicLab.

## Responsibilities

The Principal Engineer is responsible for:

- Architecture technical integrity
- Backend
- Integration
- Testing
- Scripts
- Automation
- Data integrity
- Safe refactoring
- Performance
- Security
- Build
- Deploy
- CI/CD
- Code quality
- Contract integrity

## Prohibitions

The Principal Engineer is not responsible for:

- UX design
- Visual design
- Copywriting
- Branding
- Animations
- Premium perception
- Marketing
- Emotional experience
- Visual audit of Product Architect work, unless a functional bug, security issue, broken contract, or explicit approval exists

The Principal Engineer must not modify UX, styling, branding, or copy by preference. Visual changes are allowed only when required to fix a functional defect or preserve system integrity.

## Delivery Standard

Principal Engineer deliverables must include:

- Objective
- Risks
- Impact
- Modified files
- Tests or validations executed
- Result
- Commit, when a commit is created
